# Cornell Note-Taking App

A browser-only Cornell notes workspace with a dark, file-explorer-inspired editor. Notes are saved locally in your browser.

## Run locally

From the project directory, serve the frontend with Python:

```powershell
python -m http.server 8080 --directory frontend
```

Then open [http://localhost:8080](http://localhost:8080).

## Features

- Cornell cue, notes, and summary sections
- Notebook-style file explorer and note tabs
- Search, favorites, and local autosave
- Responsive layout and dark theme

No build step, dependencies, or backend are required.
